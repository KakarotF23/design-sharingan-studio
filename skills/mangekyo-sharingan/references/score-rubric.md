# Mangekyo Heuristic Score Rubric

Use only when a numeric summary helps. Rate each dimension 0–4 and write one evidence sentence. The total is a communication aid, not an objective computer-vision metric.

| Dimension | Weight | What 4 means |
|---|---:|---|
| UX integrity | 5 | Approved flow, actions, navigation, states intact |
| Design-system consistency | 5 | Tokens/components/patterns are coherent with product |
| Visual hierarchy | 5 | Attention order matches approved intent immediately |
| Accessibility | 5 | No known interaction/contrast/state regressions |
| Reference intent | 4 | The transferable design logic is strongly present |
| Typography & spacing | 3 | Rhythm and scale are disciplined and coherent |
| Pixel similarity | 1 | Useful only where similarity actually matters |

Never hide CRITICAL issues behind a high weighted average. Any CRITICAL finding forces overall status to FAIL regardless of score.
