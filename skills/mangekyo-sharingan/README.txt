Design Sharingan V2 — Mangekyo Sharingan

Purpose:
  Evidence-backed visual refinement loop for Codex UI work.

Install globally:
  bash scripts/install.sh

Or copy this folder to:
  ~/.agents/skills/mangekyo-sharingan

Then restart Codex / open a new session.

Recommended explicit invocation:
  $mangekyo-sharingan loop

Special modes:
  $mangekyo-sharingan amaterasu
  $mangekyo-sharingan tsukuyomi
  $mangekyo-sharingan susanoo
  $mangekyo-sharingan kamui

V1 relationship:
  design-sharingan = reference analysis / UX direction / Design DNA
  mangekyo-sharingan = approved UI implementation / render / compare / refine loop

Important:
  V2 can only run a true visual loop when the Codex environment can render the target UI and capture the resulting screen. If those tools are unavailable, it must switch to audit-only mode instead of inventing visual evidence.

Verification:
  references/pressure-tests.md contains pressure scenarios to run after installation.
