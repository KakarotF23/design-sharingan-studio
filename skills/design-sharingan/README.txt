Design Sharingan v1

Install globally for Codex:
  bash scripts/install.sh

Or copy this folder to:
  ~/.agents/skills/design-sharingan

Then restart Codex / open a new Codex session.

Explicit invocation examples:
  $design-sharingan scan
  $design-sharingan assimilate
  $design-sharingan evolve
  $design-sharingan verify

Implicit invocation is enabled in agents/openai.yaml.
