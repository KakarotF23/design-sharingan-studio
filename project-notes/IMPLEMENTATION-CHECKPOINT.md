## Phase-Based Autopilot Development Policy

Codex development proceeds autonomously within the currently approved phase:

- Phase 1 — Foundation: Tasks 1–6 (in progress; Tasks 1–5 verified)
- Phase 2 — Design Intelligence: Tasks 7–10
- Phase 3 — Mangekyō: Task 11
- Phase 4 — Eternal + Final Verification: Tasks 12–16

Routine task transitions do not require human approval. Each task still uses
RED → GREEN TDD, tests, typecheck, independent review, and a verified commit.
Human review occurs at phase boundaries or when a genuine product,
architecture, security, permission, destructive-operation, or unresolved
verification decision is required.

This is a development-process policy only. Application-level Safe Mode,
Mangekyō policy limits, Human Gates, and approval-engine behavior remain
unchanged and authoritative.
